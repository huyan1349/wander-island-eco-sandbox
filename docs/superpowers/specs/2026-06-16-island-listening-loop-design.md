# 流浪岛 · 核心留存循环与内容系统设计

> 代号「**倾听之环**」（The Listening Loop）
> 日期：2026-06-16 ｜ 状态：设计稿（待业主评审）
> 范围：本轮**不碰「生生不息」卡牌模式**，专注把现有自由模式做成一个"留得住人"的完整游戏。
> 对应业主提的 5 件事：①新手引导 ②辞的主动性/反应 ③遗迹破水而出 ④建模 ⑤留存。

---

## 0. 一句话愿景 & 核心隐喻

> **你不是在建岛，你在「倾听」一座岛慢慢醒来。**
> 你照顾得越好，岛醒得越多；醒得越多，它想起的越多；想起的越多，可照顾的就越多。

世界观里玩家是「潮语者」，核心动词是**倾听**——通过营造生态条件，让碎片上沉睡的记忆重新开口。
本设计把这个隐喻**做成一个真实的循环引擎**，而不是停留在设定集里。五件事不是并列的五个功能，而是**「1 个引擎 + 4 个仪器」**：

```
                  ┌─────────────────────────────────┐
                  │   留存引擎：倾听之环 (⑤)         │
                  │   主线变量 = 「苏醒度」          │
                  └─────────────────────────────────┘
                     ▲          ▲          ▲        ▲
        ┌────────────┘    ┌─────┘     ┌────┘    └───────┐
   ①新手引导        ②辞 AI       ③遗迹奇观        ④建模
  （教第一圈）   （陪伴+路标）  （里程碑正反馈）  （内容载体）
```

只要引擎钉死，其余四件全部顺着它长出来：引导教的是这一圈循环、辞反应的是循环里的有意义事件、遗迹由循环的进度变量触发、建模优先做循环最先需要的东西。

## 1. 问题诊断：为什么现在留不住

| 现状 | 代码证据 | 后果 |
|---|---|---|
| 沙盒无目标、无尽头 | 自由模式无 win/lose/进度变量 | 玩家放几棵树就不知道"为什么继续" |
| Eco 只涨不跌、无上限 | `store.ts:685` `finalEP = ecoPoints + passiveEP`，无 sink | 经济失去意义，攒资源没用 |
| 生态是"全局一个数"，很浅 | `grassHealth` 单一 0-100（`store.ts:596`） | 看着活，不构成有趣决策 |
| 辞是无状态聊天，且**没接生态** | `ciLines.ts:buildCiSystemPrompt` 只注入天气/季节/好感，**无生态健康度** | 招牌卖点"生态崩溃→辞只能说单词"实际不成立 |
| 世界观招牌系统零实现 | grep `碎片/叙事图谱` 全代码库无匹配 | 唯一的"意义层"只在 PDF 里 |

**结论**：游戏的"外壳"（美术/氛围/世界观）已达发行水准，缺的是一根**进度脊柱**和**回来的理由**。本设计就是补这根脊柱。

## 2. 留存引擎：苏醒度 + 三层「倾听之环」

### 2.1 主线变量：苏醒度（Awakening）

新增**一个**持久化主线变量，作为所有系统的总开关。它与现有两个变量分工明确、互不替代：

| 变量 | 时间尺度 | 作用 | 现状 |
|---|---|---|---|
| `grassHealth` 草地健康 | 秒级、易波动 | 短期生态体感（颜色/音乐清晰度） | 已有，保留 |
| `ecoPoints` Eco 能量 | 分钟级、可花费 | **建造货币**（攒起来花在奇观/出航） | 已有，**改造成有 sink** |
| **`awakening` 苏醒度** 🆕 | 小时/天级、缓慢、只升不大降 | **主线进度脊柱**：解锁一切 | 新增 |

**苏醒度只升不（轻易）降**，靠**"持续的健康"**和**"倾听的行为"**积累——它代表岛对你的信任，是长线成就感的载体。它**同时驱动**：

1. **辞的语言能力**（醒得越多，话越完整——直接落地世界观第十章）
2. **音乐清晰度**（回声越完整）
3. **Layer B** 的自发生长速度（醒得越多，自然燎原越快）
4. **Layer C** 奇观的解锁与提示时机
5. **Layer A** 碎片的浮现频率与深度

> 一根变量，串起天气、音乐、AI、生长、奇观、叙事——这正是世界观"一切相互关联"的语法。

### 2.2 三层循环（B 打底 → C 点缀 → A 收尾）

业主三种"生长"方案（A 考古 / B 生态蔓延 / C 奇观）**全部采纳**，但定位成**节奏不同的三层**，而非三选一：

| 层 | 节奏 | 玩家"回来的理由" | 借鉴竞品 | 主要状态 |
|---|---|---|---|---|
| **B · 活的花园** | 日常 / 挂机 | "我离开时它长成什么样了" | Cozy Grove 的"每日限量、慢生长" | 在线即转 |
| **C · 奇观** | 周期高点 | "我还没解开的秘密/奇观" | Tiny Glade 的"惊喜涌现" | 里程碑触发 |
| **A · 考古叙事** | 长线终局 | "下一块碎片 / 拼完图谱" | Obra Dinn 的"碎片拼装即解谜" | 收集进度 |

一个健康的玩家时段长这样：

```
进岛 → 看 B 层这段时间自己长出的草/树苗/新来的动物（即时治愈正反馈）
     → 顺手照料、补种、修整（核心 cozy 操作）
     → 苏醒度悄悄涨过一个台阶 → 辞给出一句奇观线索（C 层钩子）
     → 凑齐"阵法" → 遗迹破水而出（C 层奇观高潮 + 掉落碎片）
     → 碎片进入叙事图谱，拼亮一个节点 → 触发一段环境叙事（A 层意义兑现）
     → 心满意足下线，期待明天它又长了多少
```

## 3. 状态与数据层改造（代码锚点）

> 原则：**最大化复用**，新增集中在 `store.ts` 与一个新模块，尽量不动渲染主干。

### 3.1 `store.ts` 新增

```ts
// 主线
awakening: number;                 // 0–100，持久化进存档
bumpAwakening: (delta: number) => void;

// Layer B：逐格生态（与 terrainData.types 同维度）
ecoGrid: Uint8Array | null;        // 每格"湿度/肥力"，驱动草的蔓延
tickPropagation: () => void;       // 元胞自动机一步

// Layer A：碎片
fragments: FragmentState;          // { collected: id[], graph: {...} }
surfaceFragment: (id: string, pos) => void;   // 浮现一块
collectFragment: (id: string) => void;

// Layer C：奇观
wonders: Record<WonderId, 'locked'|'hinted'|'done'>;
triggerWonder: (id: WonderId) => void;
```

### 3.2 关键复用点（已存在，直接接）

| 需要的能力 | 现成代码 | 接法 |
|---|---|---|
| 逐格地表类型（草/岩/沙…） | `terrainBrush.ts:146 paintSurface`，`types: Uint8Array` 逐面存储 | Layer B 直接改写 `types`，渲染层 `refreshTerrainColors` 自动变色 |
| "自动生成实体"范式 | 鹿自动繁殖 `store.ts:636-648`（成簇+概率 spawn） | Layer B 母树抽苗、动物到访照搬 |
| customState 状态机动画 | 海鸥亭 gather/release `Assets.tsx:3126-3135` | 遗迹上升、船出航的动画状态照搬 |
| 程序化运镜 | `GameCanvas.tsx` `controlsRef` + `SmoothZoom` lerp | 奇观时相机推近照搬 |
| 共生正反馈（绿波+和弦） | `store.ts:526 playSynergyChord` + `lastPlacedSynergy` | 引导 Aha、奇观达成复用 |
| 季节即时换装 | `setSeason` + Terrain 已对 spring/autumn/winter/tundra 变色 | 改季献祭直接调 |
| 辞气泡 + 记忆 + 好感 | `useCiProactive.ts` / `ciProgress.ts` / `ciSay`（10s 节流 `store.ts:464`） | 主动播报、碎片旁白复用 |
| 6 首回声音乐 | `ui/musicData.tsx` | A 层"还原记忆"绑定对应曲目 |
| 碎片文案 | `docs/narrative/世界观与叙事全书.md` 附录（表层/中层/深层现成几十条） | A 层文本直接取用，零写作成本 |

### 3.3 把 Eco 通胀变成特性（修经济）

不删被动产出，而是**给它出口**：奇观、远洋出航、解锁稀有物件都**花 Eco**。于是"攒 Eco→兑换奇观"成为 C 层的一条副驱动，`store.ts:685` 的只增不减从 bug 变成 feature。

## 4. Layer B｜活的花园（元胞蔓延）

**核心体验**：你只点火种，大自然自己燎原。对标 Cozy Grove 的"慢生长 = 可爱的日常仪式"。

### 4.1 机制

- **起点是死寂**：新岛大片是灰岩/枯土（`types` 的新类型值），只有中心一小块活地。
- **水的蔓延**：放下泉/池，每个 tick 向相邻格扩散"湿度"（`ecoGrid`）；湿度足够的枯土格，过几分钟自动变成草（改 `types`）。纯元胞自动机，64×64≈4k 格、逐面 8k，每 2s 跑一遍完全够。
- **树的繁衍**：种一棵"母树"，周围湿润草地上**自发抽出树苗**（Pop-in 动画），逐级长大（复用鹿 spawn 概率范式 + 现有 `growthProgress`）。
- **生灵到访**：森林簇 + 水达标，动物自己走入（已有逻辑，强化入场感）。
- **苏醒度联动**：全岛绿化率 → 苏醒度缓涨；苏醒度越高，蔓延越快（正循环）。

### 4.2 留存钩子

**离线/挂机延时摄影**：下线时记录时间戳，回来按经过时间快进若干 tick——"一觉醒来岛绿了一片"。这是日常回流的主引擎。

### 4.3 Tiny Glade 式"免费变好看"

蔓延出的草地**自动点缀**（实例化小花/草丛/蘑菇随机散布），让"自发生长"天然好看、零额外操作。这条对治愈感增益极大、成本低。

## 5. Layer C｜奇观（含「遗迹破水而出」触发设计 = 业主 Q3）

**核心体验**：最牛的东西不是买来的，是"召唤"出来的。对标 Tiny Glade 的"惊喜涌现"。

### 5.1 奇观通用框架

每个奇观 = `触发条件` + `一段编排（运镜+音效+VFX+动画）` + `永久奖励 + 掉落碎片`。
状态机 `locked → hinted → done`，全部复用 §3.2 的现成范式。

### 5.2 业主 Q3：遗迹「破水而出」到底**怎么触发**？

我比较了三种触发哲学，给出推荐：

| 方案 | 触发 | 优点 | 致命伤 |
|---|---|---|---|
| ⓐ 纯生态阈值 | 苏醒度 ≥ X 自动触发 | 简单、必然兑现 | 不像"解谜"，像系统发奖，惊喜弱 |
| ⓑ 纯隐藏配方 | 凑出"阵法"（如泉四方各一棵成年松） | 发现感强、可分享攻略 | 玩家可能**永远撞不到** → 内容白做 |
| ⭐ⓒ **分层混合（推荐）** | 苏醒度到台阶 → **辞给暗示** → 玩家照暗示凑阵法 → 触发 | 兼得"可发现"与"被引导"，且**同时用上 A/B/C 三层** | 需写一句好的暗示文案（成本极低） |

**推荐 ⓒ 的完整链路：**

1. **门槛（B/苏醒度）**：苏醒度跨过某台阶，泉水底"开始共鸣"——这是节奏阀门，保证奇观不会过早/随机出现。
2. **暗示（A/辞）**：辞弹出一句**克制而具体**的线索（落地世界观全书"摆渡人/守护者"母题）：
   > 辞：「泉底好像有什么醒了……等一下——四个方向，都需要**沉默的守望者**。」
   （"沉默的守望者" = 松树的诗化指代，玩家能猜、但不直白。）
3. **阵法（C/解谜）**：玩家在**同一眼生命之泉的四个正方向，各种一棵成年松树**（用现成的邻接/方向判定，参考 `flourish.ts:hasNeighbor` 的距离判定范式）。
4. **奇观（编排）**：条件达成瞬间——
   - 音乐骤轻、辞惊叹号；
   - 相机自动推近（`SmoothZoom`/`controlsRef`）；
   - 泉水剧烈沸腾、喷射粒子 + 低沉轰鸣音效；
   - `RuinsArch`（`Assets.tsx:3889`）Y 从 -5 缓慢 Lerp 到 0 破水而出（**动画状态机直接照搬海鸥亭 customState 范式**）；
   - 顶部射出光柱。
5. **奖励**：**永久提高苏醒度上限/产出**（即世界观说的"提升生态上限"——注意：当前**无"生态上限"概念，需新建**这个变量）+ **掉落一块深层碎片**（接入 A 层）。

> 这套之所以好：门槛由 B 把节奏、暗示由 A 给线人、解谜与奇观由 C 兑现。一个奇观把三层缝在一起。

### 5.3 首发三个奇观（按性价比）

| 奇观 | 触发 | 复用 | 奖励 |
|---|---|---|---|
| **遗迹破水**（旗舰） | 苏醒度台阶 + 泉四方四松（见上） | RuinsArch、运镜、customState | 苏醒度上限↑ + 深层碎片 |
| **远洋出航** | 点击岸边小船，花 100 Eco 派遣 | Boat `Assets.tsx:1934`、`connections[]`（绳子自动断） | 真 3 分钟后归来，带回稀有种子/碎片 |
| **神树改季** | 向远古神树供奉过剩作物到阈值 | SpiritTree `Assets.tsx:3726`、`setSeason` | 强行改季 → 解锁该季限定动植物 |

## 6. Layer A｜考古叙事（碎片 → 叙事图谱 → 环境叙事）

**核心体验**：玩到后面，是在**把一座岛的记忆拼回来**。对标 Obra Dinn——**拼装本身就是解谜**。

### 6.1 碎片浮现

- 生态/苏醒度/时间/天气达条件时，岛上**浮现半透明发光文字motes**（drei `Text`/`Html` + 粒子）。
- 浮现频率与"深度"随苏醒度提升（表层"回声"→ 中层"残句"→ 深层"遗书"，文案全在世界观全书附录，直接取用）。
- 点击 → 收集，存进 `fragments.collected`。

### 6.2 叙事图谱（Obra Dinn 式拼装板）

- 一个**星座/网络面板**：每块碎片是一个节点，叙述中原本相邻的碎片之间出现连线。
- 玩家**手动把相关碎片归到同一"回声"母题下**（如"灯塔/守灯人"组），归对了节点亮起——**拼装即解谜，给玩家"侦探"成就感**，而非被动读文。

### 6.3 环境叙事兑现（终局）

- 当某个母题的碎片集齐：触发一段**环境叙事**——特定光照 + 播放该母题对应的**回声音乐**（`musicData.tsx` 现成 6 首）+ 辞**朗读那段深层遗书**。
- 世界观说的"和声重新响起"= 集齐全部 6 个母题 → 终局演出。这是整个游戏的情感终点和长线目标。

## 7. ①新手引导：实操型微任务

**目标**：废除"连点 7 次下一步"，改为**做中学**，并借第一圈把 B 层"点火种"和共生 Aha 教给玩家。

| 步 | 辞的话（示例） | 机制 | 复用 |
|---|---|---|---|
| 1 第一声心跳 | "这座岛沉睡太久了。先种下一棵**母树**，听听风。" | 高亮建造栏对应按钮；**阻塞**直到真的种下 | `selectedTool`/`addAsset` |
| 2 生态共生（Aha） | "树木很渴……在它旁边放一口**生命之泉**。" | 放置触发"水土丰茂"绿波+和弦，**并让第一格草肉眼可见地蔓延出去**（教 B 层核心） | `lastPlacedSynergy`、`playSynergyChord`、§4 蔓延 |
| 3 引来生灵 | "有了林和水，也许会有访客。引一只**鹿**来。" | 放置鹿/鹿到访，动起来 | 现有动物 AI |
| 4 安营扎寨 | "天暗了。为自己立一个**营火**吧，作为故事的起点。" | 放置后引导结束，**辞递给玩家第一块碎片**（埋 A 层钩子）："岛……开始想起一点事了。" | §6 碎片 |

**技术**：一个小型引导状态机（当前步、完成判定、按钮高亮遮罩、阻塞推进）。低风险、低工作量、最高 ROI——**建议第一个落地**。

## 8. ②辞 AI：语言绑定生态 + 主动 + 反应

### 8.1 语言能力绑定苏醒度（招牌功能，当前未接！）

在 `ciLines.ts:buildCiSystemPrompt` 注入**苏醒度/生态等级**，并加**硬性长度约束**，第一次让世界观第十章成立：

| 苏醒/生态档 | 约束（写进 system prompt） |
|---|---|
| 死亡 | **沉默**（不回，或只回"……"） |
| 崩溃 | 只能用**单个词**："等待""光""循环" |
| 一般 | 只能用**短语**，梦呓感 |
| 良好 | 完整句子，可有逻辑跳跃 |
| 极佳 | 可说**完整段落/小故事**，书在朗读自己 |

> 这是辞区别于任何通用 chatbot 的唯一支点。几行 prompt 改动，价值极高。

### 8.2 更主动（路标层）

扩展 `useCiProactive.ts` 的触发源（保留 10s 节流防话痨）：奇观将临的暗示（§5.2）、碎片浮现提示、B 层生长里程碑（"那棵母树有后代了"）、天气/季节、长时间 idle 陪伴。高频环境句走本地 `ci/lines.ts`（不烧 token），对话才走 DeepSeek。

### 8.3 对玩家说的话有反应（反应层）

聊天已接 DeepSeek（`socket.ts:170 deepseek-chat`）。增强**上下文注入**，让辞**接得住话茬、记得住事**：

- 注入**当前岛况快照**（最近放了什么、苏醒档、绿化率、刚发生的奇观）。
- 注入 `ciProgress.ts` 的**记忆摘要**（已有 affinity/memory 基建）。
- 玩家说"我刚种了棵樱花" → 辞能就着这件事回应，而不是泛泛而谈。

## 9. ④建模：风格规范 + 优先级清单

### 9.1 风格铁律（保持统一，别引入异物）

游戏是**flat-shading 低多边形 + `vertexColors` + 纯程序化几何**（`Terrain.tsx:809 vertexColors`）。

- ✅ 用 Three.js 基本体拼 + `flatShading` + 顶点上色，**全程序化**，与现有 40+ 物件同源。
- ❌ **不引 glTF 写实模型**（详细计划 B 的路线 A）——会和手作低多边形**风格打架**，且拖首屏。鹿/狼/金鱼"建模糙"应走**路线 B：程序化精修**（更合理比例 + flatShading 圆滑 + 耳/尾/鳍），保持一致性。

### 9.2 优先级（跟着循环走）

| 优先 | 模型 | 服务于 | 备注 |
|---|---|---|---|

| P0 | **枯土/灰岩地表色** + **草地自动点缀**（实例化小花草） | B 层 | 多为 `types` 配色 + InstancedMesh |

## 11. 落地路线图（阶段 / 复用 / 风险）

> 每阶段独立可玩、可验收；先低风险高 ROI。每步收尾跑 `tsc --noEmit` + `vite build`。

| 阶段 | 内容 | 复用度 | 风险 | 价值 |
|---|---|---|---|---|
| **P0｜地基** | 苏醒度变量 + 存档；辞语言绑定生态（§8.1）；Eco 出 sink | 高 | 低 | 立刻补上"脊柱"和招牌卖点 |
| **P1｜引导** | 实操微任务（§7） | 高 | 低 | 首启留存、教会核心 |
| **P2｜奇观旗舰** | 遗迹破水而出全链路（§5.2） | 高 | 中 | 最高 wow/工作量比 |
| **P3｜活的花园** | 逐格 `ecoGrid` 元胞蔓延 + 离线生长 + 自动点缀（§4） | 中 | 中 | 日常回流主引擎 |
| **P4｜考古叙事** | 碎片浮现 + 叙事图谱 + 环境叙事（§6） | 中（文案现成） | 中高 | 长线意义层、终局 |
| **P5｜扩展** | 远洋出航、神树改季、群岛、动物精修 | 高 | 低 | 内容厚度 |

**明确放后/不做（YAGNI）**：

- 「生生不息」卡牌模式——本轮**冻结**。
- **真·地形网格扩张**（`SEGMENTS` 硬编码、破坏存档）——用"在现有网格内动画抬升高度"伪造"拔地而起"，真扩张永久后置。
- **glTF 写实模型**、**splatmap shader**——与风格冲突，不做。
- 物件**吸附**——排在引导/奇观之后再补。

  if grassHealth > 80 且 有水有树:  awakening += 0.05    // 持续健康才涨

  生态崩溃（grassHealth < 20 持续）: awakening 缓慢回落（封顶不低于已解锁台阶，惩罚但不劝退）

档位（驱动辞/音乐/生长/奇观/碎片）：
